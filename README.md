# Avyya Singh | Personal portfolio

A personal website with internship experience, projects, campus involvement, and a pixel Pikachu companion. Plain HTML, CSS, and JavaScript with no build step.

## Preview

Run `python -m http.server 4174 --directory dist` and open http://localhost:4174. Or open `dist/index.html` directly.

## Projects

- [PatchNotes source](https://github.com/avyya-singh/patchnotes) | [Demo](https://patchnotes.vercel.app). The public demo uses sample reports; full retrieval runs locally.
- [One More Run source](https://github.com/avyya-singh/one-more-run) | [Play](https://one-more-run-avyya.vercel.app). Pixel arena with an adaptive rival, online ML, and replay tools.
- Earlier cardiovascular prediction and Flask Notes API projects.

## Source

Page content: `dist/index.html`. Styles: `dist/style.css`, `dist/anime.css`, `dist/companion.css`. Interactions: `dist/script.js`, `dist/companion.js`. Downloadable resume: `dist/resume.pdf`.

Includes light/dark themes, keyboard-accessible controls, reduced-motion support, and touch-aware companion behavior. Google Fonts have local fallbacks. No backend or analytics.

Pikachu sprite: [PokeAPI/sprites](https://github.com/PokeAPI/sprites). Pokemon character designs belong to their respective owners. See `dist/ASSET-CREDITS.txt`. Other pixel illustrations are drawn in CSS. Unused artwork from earlier explorations is excluded from Git.

This repository contains the Pikachu version. The original block portfolio is preserved separately. This portfolio has not been deployed; project demo links above are separate sites.
